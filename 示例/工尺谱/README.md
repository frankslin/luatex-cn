# 工尺谱示例

`luatex-cn` 自 v0.3.8 起支持工尺谱排版（issue [#90](https://github.com/open-guji/luatex-cn/issues/90)）。

## 文件清单

### 完整示例

| 文件 | 模板 | 说明 |
|------|------|------|
| `圣世呈符.tex` | `ltc-guji` 默认（带网格边框）+ 12 字/列 | 印本复刻 — 鹊桥仙·圣世呈符（基于 ref-2） |
| `西厢记佳期.tex` | `[红楼梦甲戌本]ltc-guji`（无网格、手写本风格）+ 18 字/列 | 手写本近似复刻 — 西厢记·佳期·临镜序（基于 ref-1） |

每个 .tex 都附 `.pdf` 编译输出和 `*-预览.png` 首页预览。

#### 模板选择

- **印本类**（如 ref-2）：用默认 `ltc-guji` 配 `\contentSetup{n-char-per-col=12, n-column=8}`，
  保留细网格线、12 字/列接近木刻印本密度。
- **手写本类**（如 ref-1）：用 `\documentclass[红楼梦甲戌本]{ltc-guji}`，无网格、字间紧密，
  接近抄本质感。草书字体本项目暂无法复刻，只能用 TW-Kai 印刷体替代。

### 已知与参考的不一致

复刻只能近似，以下是当前明显的差异点（也是后续可改进方向）：

1. **手写草书字体** — ref-1 是手写草书，本项目用印刷体 (TW-Kai) 近似，无法复刻笔画风格。
2. **句/韵 句读小标记** — 印本里 `句`/`韵` 是专用小符号，目前用 `{\small ...}` 近似，
   不在主字网格上对齐。后续可考虑添加 `\句` `\韵` 命令。
3. **调名/曲牌注** — 类似 `仙吕调` 这种夹注式注释暂用 `{\small ...}` 处理，
   未来可设计专用 `\宫调` `\曲牌` 等。
4. **工尺音字精确度** — 草书工尺难辨，部分音字取常见近似而非确证。
5. **板眼密度与位置** — 印本中板眼在 gongche 字之间或字旁，本实现统一在字侧。

## API 速查

### `\工尺{主字}{右侧工尺串}`

主字 + 右侧工尺旁注（Level 1，纯字符串模式）。

```latex
\工尺{春}{尺工}        % 1 主字 + 2 工尺音
\工尺{眠}{六五四}       % 1 主字 + 3 工尺音
```

### `\工尺[opts]{主字}{右侧}`

可选参数：

| 键 | 含义 | 默认 |
|---|---|---|
| `缩放` (`scale`) | 工尺字相对主字的大小 | 0.5 |
| `颜色` (`color`) | 工尺字颜色 | black |
| `偏移` (`offset`) | 与主字的水平间距 | 0pt |

```latex
\工尺[缩放=0.6, 颜色=blue]{大}{尺工}
```

### `\工尺设置{...}`

全局默认值（同上键）。

```latex
\工尺设置{颜色=black, 缩放=0.55}
```

### `\音[<options>]{字}`

工尺字 + 两个正交装饰槽位（板眼 / 八度），可同时启用。仅在 `\工尺` 的右侧参数内使用。

#### 板眼槽位（rhythm slot）

| 预设 | 效果 |
|------|------|
| `\音{尺}` | 工尺字，无标记 |
| `\音[板]{尺}` | 红色 `。` 板点（重拍） |
| `\音[眼]{尺}` | 红色 `、` 眼点（轻拍） |
| `\音[头板]{尺}` | 红色 `×` 头板 |
| `\音[底板]{尺}` | 红色 `└` 底板（休止） |
| `\音[底叮]{尺}` | 红色 `⌐` 底叮 |

#### 八度槽位（octave slot）

| 预设 | 效果 | 出处 |
|------|------|------|
| `\音[高]{尺}` | `亻` 前缀（高八度） | 闽剧 / 粤剧 |
| `\音[低]{尺}` | `彳` 前缀（低八度） | 粤剧 |
| `\音[昆低]{尺}` | `⌒` 钩（低八度） | 昆曲 |

#### 组合与覆盖

```latex
% 板 + 高 同时使用 (双槽位)
\音[板, 高]{尺}

% 颜色/缩放/字符 默认作用于板眼槽位
\音[板, 颜色=blue]{尺}                      % 蓝色板点
\音[字符=●, 缩放=0.3, 颜色=green]{尺}        % 完全自定义板眼

% 八度槽位用专用键 八度颜色 / 八度字符 / 八度缩放 覆盖
\音[高, 八度颜色=blue]{尺}                  % 蓝色 亻
\音[八度字符=亻, 八度颜色=green]{尺}         % 完全自定义八度
```

### `\拖音[<rhythm>]`

延音线 — 单个续拍单元（用 `丨` 字符占位）。继承所有 `\音` 的板眼/八度选项。

```latex
% 4 拍长音 — 第 1 拍发声 + 3 拍延续
\工尺{春}{\音[板]{尺}\拖音[眼]\拖音[板]\拖音[眼]}

% 简单 1 拍延音 (无板眼)
\工尺{延}{\音{尺}\拖音}
```

每个 `\拖音` 占一个 unit 高度，渲染为一根细竖线，自然堆叠在前一个工尺字下方。

### 完整示例

```latex
\工尺{春}{\音[板]{尺}\音[眼]{工}}%
\工尺{眠}{\音[板]{六}}%
\工尺{不}{\音[眼]{五}\音[板]{尺}}%
\工尺{觉}{\音[眼]{工}}%
\工尺{晓}{\音[板]{六}\音[眼]{五}}
```

# 工尺谱示例

`luatex-cn` 自 v0.3.8 起支持工尺谱排版（issue [#90](https://github.com/open-guji/luatex-cn/issues/90)）。

| 文件 | 说明 |
|------|------|
| `春眠工尺谱.tex` | 完整示例 — 孟浩然《春晓》配工尺谱 |
| `春眠工尺谱.pdf` | 编译输出 |
| `春眠工尺谱-预览.png` | 首页预览图 |

| `ref-3-rotated.png` | 参考样本 3：现代铅印本（书页斜拍） |

## API 速查

### `\工尺{主字}{右侧工尺串}`

主字 + 右侧工尺旁注（Level 1，纯字符串模式）。

```latex
\工尺{春}{尺工}        % 1 主字 + 2 工尺音
\工尺{眠}{六五四}       % 1 主字 + 3 工尺音
```

### `\工尺[opts]{主字}{右侧}`

可选参数：

| 键 | 含义 | 默认 |
|---|---|---|
| `缩放` (`scale`) | 工尺字相对主字的大小 | 0.5 |
| `颜色` (`color`) | 工尺字颜色 | black |
| `偏移` (`offset`) | 与主字的水平间距 | 0pt |

```latex
\工尺[缩放=0.6, 颜色=blue]{大}{尺工}
```

### `\工尺设置{...}`

全局默认值（同上键）。

```latex
\工尺设置{颜色=black, 缩放=0.55}
```

### `\音[<板眼>]{字}`

工尺字 + 单位级装饰（板眼/八度等）。仅在 `\工尺` 的右侧参数内使用。

| 预设 | 效果 |
|------|------|
| `\音{尺}` | 工尺字，无标记 |
| `\音[板]{尺}` | 红色 `。` 板点（重拍） |
| `\音[眼]{尺}` | 红色 `、` 眼点（轻拍） |
| `\音[头板]{尺}` | 红色 `×` 头板 |
| `\音[底板]{尺}` | 红色 `└` 底板（休止） |
| `\音[底叮]{尺}` | 红色 `⌐` 底叮 |

支持手动覆盖：

```latex
\音[板, 颜色=blue]{尺}                      % 预设 + 改色
\音[字符=●, 缩放=0.3, 颜色=green]{尺}        % 完全自定义
```

### 完整示例

```latex
\工尺{春}{\音[板]{尺}\音[眼]{工}}%
\工尺{眠}{\音[板]{六}}%
\工尺{不}{\音[眼]{五}\音[板]{尺}}%
\工尺{觉}{\音[眼]{工}}%
\工尺{晓}{\音[板]{六}\音[眼]{五}}
```

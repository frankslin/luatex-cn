# 工尺谱示例

`luatex-cn` 自 v0.3.8 起支持工尺谱排版（issue [#90](https://github.com/open-guji/luatex-cn/issues/90)）。

| 文件 | 说明 |
|------|------|
| `春眠工尺谱.tex` | 完整示例 — 孟浩然《春晓》配工尺谱 |
| `春眠工尺谱.pdf` | 编译输出 |
| `春眠工尺谱-预览.png` | 首页预览图 |

## API 速查

### `\工尺{主字}{右侧工尺串}`

主字 + 右侧工尺旁注（Level 1，纯字符串模式）。

```latex
\工尺{春}{尺工}        % 1 主字 + 2 工尺音
\工尺{眠}{六五四}       % 1 主字 + 3 工尺音
```

### `\工尺[opts]{主字}{右侧}`

可选参数：

| 键 | 含义 | 默认 |
|---|---|---|
| `缩放` (`scale`) | 工尺字相对主字的大小 | 0.5 |
| `颜色` (`color`) | 工尺字颜色 | black |
| `偏移` (`offset`) | 与主字的水平间距 | 0pt |

```latex
\工尺[缩放=0.6, 颜色=blue]{大}{尺工}
```

### `\工尺设置{...}`

全局默认值（同上键）。

```latex
\工尺设置{颜色=black, 缩放=0.55}
```

### `\音[<options>]{字}`

工尺字 + 两个正交装饰槽位（板眼 / 八度），可同时启用。仅在 `\工尺` 的右侧参数内使用。

#### 板眼槽位（rhythm slot）

| 预设 | 效果 |
|------|------|
| `\音{尺}` | 工尺字，无标记 |
| `\音[板]{尺}` | 红色 `。` 板点（重拍） |
| `\音[眼]{尺}` | 红色 `、` 眼点（轻拍） |
| `\音[头板]{尺}` | 红色 `×` 头板 |
| `\音[底板]{尺}` | 红色 `└` 底板（休止） |
| `\音[底叮]{尺}` | 红色 `⌐` 底叮 |

#### 八度槽位（octave slot）

| 预设 | 效果 | 出处 |
|------|------|------|
| `\音[高]{尺}` | `亻` 前缀（高八度） | 闽剧 / 粤剧 |
| `\音[低]{尺}` | `彳` 前缀（低八度） | 粤剧 |
| `\音[昆低]{尺}` | `⌒` 钩（低八度） | 昆曲 |

#### 组合与覆盖

```latex
% 板 + 高 同时使用 (双槽位)
\音[板, 高]{尺}

% 颜色/缩放/字符 默认作用于板眼槽位
\音[板, 颜色=blue]{尺}                      % 蓝色板点
\音[字符=●, 缩放=0.3, 颜色=green]{尺}        % 完全自定义板眼

% 八度槽位用专用键 八度颜色 / 八度字符 / 八度缩放 覆盖
\音[高, 八度颜色=blue]{尺}                  % 蓝色 亻
\音[八度字符=亻, 八度颜色=green]{尺}         % 完全自定义八度
```

### 完整示例

```latex
\工尺{春}{\音[板]{尺}\音[眼]{工}}%
\工尺{眠}{\音[板]{六}}%
\工尺{不}{\音[眼]{五}\音[板]{尺}}%
\工尺{觉}{\音[眼]{工}}%
\工尺{晓}{\音[板]{六}\音[眼]{五}}
```
